# Cabin Reference Set

These files are Sean-authored visual and layout references for Phase 12.
They are source material, not executable instructions. Direct instructions in
`docs/development/PHASE-12.md` remain authoritative when a photograph is
ambiguous.

## Layout Authority

- `authored-map-layout.jpeg` — primary spatial authority for the outdoor
  grounds, cabin footprint, both porches and stairs, both doors, interior
  furniture, firepit, shed, RGB-light positions, and other labeled landmarks.

The drawing is schematic rather than tile-scaled. Preserve its relative
placement and circulation while translating it to native 320x180 gameplay.
Do not "improve" the real cabin into a generic game-house layout.

## Exterior References

- `cabin-front-and-stairs.jpeg` — front elevation, covered porch, central
  stairs, lattice, weathered blue-gray siding, and surrounding vegetation.
- `cabin-side-and-covered-porch.jpeg` — side wall, raised foundation, broad
  roof overhang, wraparound covered porch, and forest relationship.
- `cabin-roof-and-lattice.jpeg` — shallow gable, mossed roof, porch lattice,
  roof supports, and dense Douglas-fir canopy.
- `night-firepit-and-outbuilding.jpeg` — night palette, firepit, rough forest
  floor, barrels/outbuilding, and the darkness beyond the clearing.
- `color-changing-mushroom-lights.jpg` — form and multi-color behavior of the
  small outdoor path lights. This product image is a lighting reference only;
  no branding or storefront UI belongs in the game.

## Interior References

- `interior-kitchen.jpeg` — brown wood paneling, low warm lighting, sink,
  counters, cabinets, windows, and compact kitchen character.
- `interior-couch-and-stove.jpeg` — large couch, dark freestanding wood stove,
  hearth area, paneling, and lived-in proportions.
- `interior-chairs-and-woodstove.jpeg` — two upholstered wooden chairs, stove
  pipe, rug/floor colors, and Chuck-to-furniture scale.

The photographs establish materials, palette, age, and scale. The authored
layout drawing determines where those elements belong.
