## Work That Is Not A Phase

Closing the sequence does not close the repository. Some work is technical
rather than creative -- it changes no game content, adds no region, and opens
no phase -- and it continues under the Baton at the top of
[`HANDOFF.md`](HANDOFF.md) rather than under a phase contract.

[`WEB-BUILD.md`](WEB-BUILD.md) is the standing example: running the game in a
browser and publishing it from GitHub Pages. The mobile touch shell at
`/mobile/` is the current one. Both are side tangents off the main game, and
neither needs a phase document to proceed.

The distinction that matters: this is not a licence to build game content
outside the phase system. AGENTS.md's stop conditions still hold, and a change
that would alter the game's identity, controls, scale, tone, or rules is a
creative decision and still Sean's. Adding a way to type a save code on a phone
is not. Adding a region is.
