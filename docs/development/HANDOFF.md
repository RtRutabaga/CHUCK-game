## Completed This Pass

The Waterdeep pantry's jars are now scratch-breakables that spill cigarette
cartons. The jars live painted on the two pantry shelf sprites, so the
implementation honors that literally: the shelf furniture stands forever
(solid, human-scale, mute), but one scratch at a shelf's base rattles all
its jars down in a burst of glazed ceramic shards and spills one
CigaretteCarton — the same 20-cigarette pickup the temple urns use, sanity
clamped at full, the count reserved for the future cigarette counter.

After the debris pass the shelf keeps drawing with a dedicated bare sprite
(`pantry_shelf_empty.png`, generated by the same text-grid builder as the
stocked one). A second scratch is inert. Both shelves restock on map
reload, matching every other breakable's checkpoint lifecycle.

Drop safety: the scene computes each carton's landing tile (below, then
diagonal/side neighbors) accepting only plain walkable board — necessary
because the LEFT shelf stands directly above an Astral fall tile, and a
carton must never land where collecting it kills. The left carton therefore
lands one tile aside; the right lands directly below.
