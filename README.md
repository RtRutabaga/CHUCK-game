# CHUCK

CHUCK is a pixel-art exploration game about a one-foot-tall rat crossing a
world whose regions have been joined together incorrectly.

The browser build is prepared for GitHub Pages at:

https://rtrutabaga.github.io/CHUCK-game/

The Pages workflow must first be enabled under **Settings → Pages → Source →
GitHub Actions**. Until the workflow has run successfully, use the local browser
instructions in [`chuck/chuck/WEB-README.md`](chuck/chuck/WEB-README.md).
